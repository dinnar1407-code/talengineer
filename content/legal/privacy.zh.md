这是一份用平实语言写成的说明，描述 Talengineer 平台**当下实际**收集你的哪些数据、用来做什么。我们追求准确，而不是堆砌法律术语。**本文件是草稿，正在等待法务审核**——如果任何条款不清楚，或你希望更正、导出、删除你的数据，请发邮件到 **hello@talengineer.us**，会有真人回复。

Talengineer（"我们"）运营 talengineer.us 网站与撮合市场，连接出海制造企业（"雇主"）与工业自动化工程师（"工程师"）。

## 我们收集什么

**账户基础信息。**注册时我们存储你的邮箱、角色（雇主或工程师）和密码。密码只以加盐 bcrypt 哈希形式存储——我们无法读取你的密码，也绝不明文存储。

**登录会话。**登录后，浏览器会在 localStorage 中保存一个签名的会话令牌（JWT），让你保持登录状态。令牌 24 小时后过期。<!-- 来源：src/routes/auth.js JWT_EXPIRES_IN -->

**雇主认证（KYC）。**希望为项目注资的雇主需提交公司名称，并可选填公司网站与电话。这些信息由我们的团队人工审核；我们会记录提交时间、审核状态和审核备注。

**工程师档案。**工程师自主提供并向雇主展示的职业信息：技能、时薪、经验、作品集与头像。筛选与认证结果（见下文）会附在档案上。

**技术筛选与认证考试。**工程师需通过一套 AI 主持的技术筛选，并可参加认证考试。我们存储你的作答内容及 AI 生成的评分与反馈。考试答案借助 Google Gemini 模型评分，且每一张证书发放前都经过人工管理员复核——仅凭 AI 输出永远不会直接发证。

**背景核查。**目前的背景核查流程是人工的：由管理员审阅证据，记录通过/不通过状态，并可附证据链接与有效期。我们没有启用任何自动化的第三方背调 API。

**税务文件（W-9）。**工程师可以上传 W-9 表格。这些文件存放在不可公开访问的私有存储桶中；只有管理员能通过短时签名 URL（约 5 分钟有效）查看，审核状态一并记录。<!-- 来源：src/routes/uploads.js / src/routes/tax.js 私有桶 + 短时签名 URL -->

**其他上传。**头像、作品集、完工照片和保险证明（COI）都通过统一的上传入口提交，接受 JPG、PNG、WebP 和 PDF 格式，单文件上限 5 MB。<!-- 来源：src/routes/uploads.js MAX_FILE_SIZE / ALLOWED_MIME -->

**驻场工作的 GPS 签到。**工程师对已注资的驻场里程碑签到时，签到可以附带 GPS 坐标。我们的服务器会将其与项目现场坐标比对（"地理围栏"）。这一比对**仅作提示**——越界签到照常成功，结果只是被记录下来，供雇主与管理员查看。我们不在其他任何时刻追踪位置；坐标只在签到那一刻采集。

**项目消息与机器翻译。**你在项目工作区发送的消息会被存储，以便双方查阅对话。为支持跨语言协作，消息文本会被发送到 Google Gemini API 进行翻译。原始消息始终是权威记录。

**支付。**支付基于 Stripe。雇主为里程碑注资时，通过 Stripe 托管的 Checkout 页面付款——**银行卡号绝不经过我们的服务器**，我们也从不存储卡号。工程师收款使用 Stripe Connect；收款所需的身份与银行信息由 Stripe 收集和保管，而不是我们。我们只存储运行托管所需的支付状态、金额与账本记录。

**Newsletter。**如果你在成本计算器、白皮书或页脚表单留下邮箱，我们会将其存入订阅者列表。我们尚未发送过任何 newsletter 邮件；将来发送时每封都会带退订链接，你也可以随时发邮件给我们退订。

## 我们如何使用这些数据

上述数据用于运营这个撮合市场：为项目匹配工程师、运行里程碑托管、发放认证、处理纠纷、发送事务性邮件（经 Resend），以及保障服务安全。我们不出售你的数据，站点上也没有广告网络或广告追踪器。

## 谁会处理你的数据

我们依赖少数几家基础设施服务商，每一家只接触其职责所需的数据：

| 服务商 | 处理内容 |
| --- | --- |
| Supabase | 托管我们的 PostgreSQL 数据库与文件存储 |
| Railway | 托管应用服务器 |
| Stripe | 处理付款与工程师收款（银行卡与银行账户数据保存在 Stripe） |
| Google（Gemini API） | AI 需求解析、考试评分与消息翻译 |
| Resend | 发送事务性与通知邮件 |
| Sentry | 收集错误报告，帮助我们修复故障 |

## Cookie 与本地存储

我们不使用广告或第三方追踪 Cookie。站点在浏览器 localStorage 中存储若干项：主题选择（`tal-theme`）、语言选择（`tal_lang`）、登录后的会话与按账户缓存的角色（`tal_user`、`tal_role_<email>`），以及记住你已关闭 App 安装提示的标记（`tal_pwa_install_dismissed`、`tal-ios-a2hs-dismissed`）。管理员登录还会额外存储 `tal_admin_token`。清空浏览器存储即可全部移除。<!-- 来源：hooks/useTheme.js / hooks/useLang.js / pages/finance.jsx / pages/admin.jsx / components/PwaSetup.jsx -->

## 保留、更正与删除

账户与交易记录在账户有效期内保留，财务与纠纷相关记录按需要的期限保留。如需更正数据、导出数据或删除账户，请用注册邮箱发信至 **hello@talengineer.us**。删除请求目前由团队人工处理；必须保留的记录（例如已完成支付的账本条目）可能在法规要求范围内继续保留。

## 安全

除了密码哈希与卡数据由 Stripe 保管之外，敏感文件存放在行级安全策略全面拒绝（deny-all RLS）的私有桶中——所有访问都经过服务端，管理员也只能通过短时签名 URL 查看税务文件。如果你发现安全问题，请报告至 **hello@talengineer.us**。

本文件处于草稿状态期间，可能随法务审核而修改。正式发布后的重大变更会在本页更新，并同步更新日期。

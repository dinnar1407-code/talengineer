これは、Talengineerプラットフォームが現在実際にどのようなデータを収集し、それをどう扱っているかを平易な言葉で説明したものです。網羅的な法律文書ではなく、正確さを重視して書かれています。**本書は法務レビュー待ちのドラフトです**——不明な点がある場合や、データの訂正・エクスポート・削除をご希望の場合は、**hello@talengineer.us** までメールをお送りください。担当者が対応いたします。

Talengineer（「当社」）は talengineer.us でウェブサイトとマーケットプレイスを運営し、製造企業（「雇用者」）と産業オートメーションエンジニア（「エンジニア」）を結び付けています。

## 収集する情報

**アカウントの基本情報。** 登録時に、メールアドレス、役割（雇用者またはエンジニア）、パスワードを保存します。パスワードはソルト付きbcryptハッシュとしてのみ保存され、当社がパスワードを読み取ることはできず、平文で保存することも一切ありません。

**ログインセッション。** サインイン後、ログイン状態を保つため、ブラウザのlocalStorageに署名付きセッショントークン（JWT）が保存されます。トークンは24時間で失効します。<!-- 出典：src/routes/auth.js JWT_EXPIRES_IN -->

**雇用者確認（KYC）。** プロジェクトに資金を投入したい雇用者は、会社名、任意で会社のウェブサイトと電話番号を提出します。これらは当社チームが手作業でレビューし、提出日時、審査結果、レビュー担当者のメモを保存します。

**エンジニアプロフィール。** エンジニアは、雇用者向けに公開することを選んだ職務情報——スキル、時間料金、経験、ポートフォリオ、アバター——を提供します。スクリーニングと認定の結果（後述）はプロフィールに紐づけられます。

**実践的なスクリーニングと認定試験。** エンジニアはAIによる実践的なスクリーニングを受け、認定試験を受験することもできます。当社は回答内容とAIが生成したスコアとフィードバックを保存します。試験の回答はGoogleのGeminiモデルの支援を受けて採点され、証明書が発行される前には必ず人間の管理者がレビューします——AIの出力だけで証明書が発行されることはありません。

**バックグラウンドチェック。** バックグラウンドチェックが記録される場合、現在のプロセスは手動です：管理者が証拠をレビューし、任意の証拠リンクと有効期限とともに合格・不合格のステータスを記録します。当社は自動化されたサードパーティのバックグラウンドチェックAPIを一切有効化していません。

**税務書類（W-9）。** エンジニアはW-9をアップロードできます。これらのファイルは一般には公開されない非公開のストレージバケットに保存され、管理者のみが短期間有効な署名付きURL（有効期限は約5分）を通じて閲覧でき、審査状況も併せて記録されます。<!-- 出典：src/routes/uploads.js / src/routes/tax.js 非公開バケット + 短期署名付きURL -->

**その他のアップロード。** アバター、ポートフォリオ、完了写真、保険証明書（COI）は、JPG・PNG・WebP・PDF形式で最大5MBまでのファイルを受け付ける単一のエンドポイントを通じてアップロードされます。<!-- 出典：src/routes/uploads.js MAX_FILE_SIZE / ALLOWED_MIME -->

**現場作業のGPSチェックイン。** エンジニアが資金投入済みの現場マイルストーンにチェックインする際、GPS座標が含まれることがあります。当社サーバーはこれをプロジェクト現場の座標（「ジオフェンス」）と比較します。この比較はあくまで参考情報です——フェンスの外でのチェックインでも成功し、結果は単に記録され、雇用者と管理者に表示されます。それ以外の時点で位置情報を追跡することはなく、座標はチェックインの瞬間にのみ取得されます。

**プロジェクトメッセージと機械翻訳。** プロジェクトワークスペースで送信されたメッセージは、双方が会話を確認できるよう保存されます。多言語チームを支援するため、メッセージ本文は翻訳のためGoogleのGemini APIに送信されます。原文のメッセージは常に正式な記録として扱われます。

**支払い。** 支払いはStripe上で処理されます。雇用者がマイルストーンに資金を投入する際は、Stripeがホストする Stripe Checkoutページで支払います——**カード番号が当社サーバーに触れることは一切なく**、当社が保存することもありません。エンジニアへの出金にはStripe Connectを使用し、出金に必要な本人確認情報や銀行情報はStripeが収集・保管し、当社は保持しません。当社はエスクローを運用するために必要な支払いステータス、金額、台帳エントリのみを保存します。

**ニュースレター。** 計算ツール、ホワイトペーパー、フッターのフォームにメールアドレスを残された場合、購読者リストに保存します。当社はこれまでニュースレターメールを送信したことはありません。送信を開始する際は、すべての配信に配信停止リンクを含め、いつでもメールで配信停止をリクエストいただけます。

## 情報の利用方法

上記のデータは、マーケットプレイスを運営するために利用します：エンジニアとプロジェクトのマッチング、マイルストーンエスクローの運用、認定の発行、紛争への対応、取引メールの送信（Resend経由）、サービスの安全性の維持などです。当社はデータを販売せず、サイト上で広告ネットワークや広告トラッカーを運用することもありません。

## データを処理する事業者

当社は少数のインフラ事業者に依存しており、各事業者は業務上必要な情報のみを受け取ります：

| 事業者 | データに対して行うこと |
| --- | --- |
| Supabase | PostgreSQLデータベースとファイルストレージをホスト |
| Railway | アプリケーションサーバーをホスト |
| Stripe | 支払いとエンジニアへの出金を処理（カード・銀行データはStripeに保持） |
| Google（Gemini API） | AI解析、試験採点、メッセージ翻訳 |
| Resend | 取引メールと通知メールを送信 |
| Sentry | 障害を修正できるようエラーレポートを収集 |

## Cookieとローカルストレージ

当社は広告目的やサードパーティのトラッキングCookieを使用しません。サイトはブラウザのlocalStorageにいくつかの項目を保存します：テーマ設定（`tal-theme`）、言語設定（`tal_lang`）、サインイン時のセッションとアカウント別ロールキャッシュ（`tal_user`、`tal_role_<email>`）、アプリインストール案内を閉じたことを記憶するフラグ（`tal_pwa_install_dismissed`、`tal-ios-a2hs-dismissed`）。管理者サインインではさらに `tal_admin_token` も保存されます。ブラウザのストレージを消去すると、これらはすべて削除されます。<!-- 出典：hooks/useTheme.js / hooks/useLang.js / pages/finance.jsx / pages/admin.jsx / components/PwaSetup.jsx -->

## 保持・訂正・削除

アカウントが有効である間、および財務・紛争記録として必要な期間、アカウントと取引の記録を保持します。データの訂正、エクスポート、アカウント削除をご希望の場合は、登録済みのアドレスから **hello@talengineer.us** までメールをお送りください。削除リクエストは現在、当社チームが手作業で対応しています。保持が義務付けられている記録（例：完了した支払いの台帳エントリ）は、必要な範囲で保持される場合があります。

## セキュリティ

ハッシュ化されたパスワードとStripeが保持するカードデータに加えて、機密文書はデフォルトで全拒否の行レベルセキュリティ（RLS）が適用された非公開バケットに保存されます——すべてのアクセスは当社サーバーを経由し、管理者も税務書類は短期間有効な署名付きURLを通じてのみ閲覧できます。セキュリティ上の問題を発見された場合は、**hello@talengineer.us** までご報告ください。
